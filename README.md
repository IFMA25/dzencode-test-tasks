## TopMenu

Шапка приложения адаптивна и корректно отображается на разной ширине экрана в соотвестии с брекпоинтами Bootstrap.

**Состоит из:**

- **Логотип** — иконка + название проекта, при клике на логотип происходит переход на главную страницу.
- **Поиск** — контекстный поиск по данным текущей страницы, подробнее в разделе Search.
- **Активные сессии** — счётчик пользователей приложения онлайн в реальном времени реализован с помощью Socket.io: сервер считает текущее число подключений и рассылает всем клиентам событие при каждом подключении/отключении.
- **Дата и время** — текущие день недели, дата и время, обновляются реактивно (`useNow` из `@vueuse/core`). День недели и месяц форматируются через `Intl.DateTimeFormat` с учётом текущего языка приложения.
- **Переключатель языка** — селект с списков доступных языков, меняет локаль приложения. Текущая локаль пользователя подхватывается автоматически. Локаль сохраняеться в локальную pinia store и при обновлении страницы локаль не сбрасывается, сохраняется в localStorage. Если локаль пользователя не поддерживаеться, то по умолчанию устанавливается английский язык.

## Sidebar

Sidebar строится динамически на основе роутов приложения и адаптивно реагирует на ширину экрана.

**Состоит из:**

- **Навигация** — пункты меню формируются автоматически из зарегистрированных роутов.
- **Активный пункт** — у текущего роута есть визуальный индикатор: в развёрнутом состоянии подчёркивается текст, в свёрнутом (иконка без текста) — иконка перекрашивается в акцентный цвет, без анимаций подчёркивания.
- **Сворачивание/разворачивание** — вручную через кнопку-стрелку либо автоматически по ширине экрана.
- **Анимация переключения текста/иконки** — при смене состояния текст и иконка плавно сменяют друг друга.
- **Профиль** — аватар пользователя и кнопка-шестерёнка поверх него, по клику открывающая страницу настроек профиля (пока с заглушкой).

## Orders (Приходы)

Список приходов реализован на базе mock-данных. Каждый элемент отображает название прихода, количество продуктов в приходе, даты создания прихода в двух форматах, сумма прихода, равная сумме цен продуктов в двух валютах и кнопку удаления прихода.

**Состоит из:**

- **Таблица** — компонент на CSS Grid, это позволяет делать карточные строки с тенью/скруглением.
- **Данные** — загружаются с бэкенда через Pinia store (`useOrdersStore`), с состояниями загрузки (лоадер) и ошибки (сообщение внутри таблицы вместо списка).
- **Удаление** — кнопка на строке открывает модальное окно подтверждения с превью удаляемого прихода. Во время запроса на кнопке подтверждения показывается лоадер, обе кнопки блокируются. При успехе список приходов перезапрашивается заново, при ошибке — всплывающее уведомление (`vue-sonner`), модальное окно при этом не закрывается.

## Groups (Группы)

Клик по приходу в таблице Orders открывает рядом со списком роут `groups/:id` — компактную панель с продуктами выбранного прихода. Список приходов при этом остаётся смонтированным, скрывается только часть его колонок.

**Состоит из:**

- **Роутинг** — `groups` зарегистрирован как дочерний роут `orders`, а не отдельная страница. Это позволяет рендерить панель продуктов рядом со списком приходов через вложенный `router-view`, без размонтирования Orders.
- **Данные** — продукты запрашиваются отдельным запросом к бэкенду (`GET /products?order=:id`) при открытии панели, а не берутся из уже загрученного в `useOrdersStore` прихода. Бэкенд — источник истины: если продукты изменились где-то ещё (пока пользователь смотрит список приходов), панель Groups всегда покажет актуальные данные, а не то, что осталось закешированным в сторе с момента загрузки списка приходов.
- **Пустое состояние** — если открыть вкладку "Группы" напрямую (не кликнув по конкретному приходу), `id` прихода отсутствует, соответственно нет и прихода, для которого нужно запрашивать продукты - панель показывает заглушку "Выберите приход" вместо пустой таблицы.

## Products (Продукты)

Список продуктов реализован на базе mock-данных. Каждый элемент отображает индикатор состояния (новый/Б/У), фото, название продукта, тип, состояние, даты гарантии в двух форматах, цену в двух валютах и название прихода, к которому относится продукт.

**Состоит из:**

- **Таблица** — тот же переиспользуемый компонент `VGridTable` на CSS Grid, что и в Orders, вынесенный в `shared/ui`.
- **Данные** — загружаются с бэкенда через Pinia store, с состояниями загрузки (лоадер) и ошибки (сообщение внутри таблицы вместо списка).
- **Фильтр по типу** — селект в toolbar-слоте таблицы, фильтрация происходит на бэкенде. Опция "Все типы" выбрана по умолчанию и корректно переводится при смене локали. Выбранный фильтр сохраняется в `localStorage` и восстанавливается при перезагрузке страницы.
- **Цена** — суммы округляются до 2 знаков после запятой; если дробная часть нулевая `.00`, она не отображается.

## Search (Поиск)

Поле поиска в TopMenu одно на всё приложение, но ищет по данным той страницы, на которой сейчас находится пользователь: на Приходах — по названию прихода, на Продуктах — по названию продукта. Фильтрация выполняется на бэкенде (`?search=`), регистр не учитывается.

**Состоит из:**

- **Фича `features/search`** — отдельная фича `SearchFeature`.
- **Запрос в URL** — введённое значение попадает в query-параметр `?search=`. Благодаря этому поиск переживает перезагрузку страницы, работает кнопка «Назад», а ссылкой с результатами можно поделиться.
- **URL как источник истины** — страницы Приходов и Продуктов сами следят за `route.query.search` и перезапрашивают данные при любом его изменении.
- **Дебаунс** — запрос уходит через 400 мс после последнего нажатия клавиши (`useDebounceFn`), поле при этом обновляется мгновенно.
- **Отмена запросов** — перед каждым новым запросом предыдущий незавершённый отменяется через `AbortController`. Отменённый запрос не показывается пользователю как ошибка.
- **Сохранение при переходе Приходы ↔ Группы** — навигация внутри этого раздела передаёт текущий `query`, поэтому найденный список не сбрасывается при открытии панели продуктов. При переходе в другой раздел параметр не передаётся и поиск очищается.
- **Пустое состояние** — если поиск ничего не нашёл, вместо «Добавьте … для отображения» показывается «По вашему запросу ничего не найдено».
